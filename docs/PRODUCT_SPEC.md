# HangulQuest — 제품 사양서 (v1.0)

> 게임 플레이만으로 자모 인식 → 글자 조합 → 단어 읽기에 도달하는 한글 학습 게임.
> 타깃: 한글을 처음 배우는 글로벌 성인 학습자(K-콘텐츠 팬층). iOS 1차, Flutter 단일 코드베이스.

---

## 1. 포지셔닝 요약 (모든 설계 결정의 기준)

| 경쟁 앱 약점 | HangulQuest의 응답 |
|---|---|
| Duolingo: 조합 원리 미교육, 기계적 음성 | 초성+중성+종성 조합이 **코어 게임 메커니즘** (2단계 글자 조립) |
| Drops: 이미지 암기 게임 + 10시간당 5분 제한 | 관대한 무료 구간(1단계 전체 + 2단계 절반) + 압도적 품질 |
| TenguGo 등: 구식 디자인, 발음 피드백 없음 | 프리미엄 게임급 아트 + 음성인식 발음 채점(4단계) |

온보딩 약속: **"7일이면 한글을 읽는다"** — 무료 구간 안에서 증명한다.

## 3. 게임 사양

### 3.1 학습 4단계

**1단계 — 자모 사냥 (무료 전체)**
- 원어민 발음(개발 단계: 고품질 TTS 플레이스홀더) 재생 → 화면의 자모 타일 중 정답 탭.
- 라운드: 10문항, 제한시간 문항당 5초. 콤보 게이지(3연속부터 배수), 정답 파티클.
- 커리큘럼: 기본 자음 14 → 기본 모음 10 → 쌍자음 5 → 복합 모음 11 순 해금.

**2단계 — 글자 조립 (전반 무료 / 후반 🔒) ★ 최우선 리소스**
- 목표 음절 제시(발음 재생) → 하단 블록 트레이에서 초성·중성·종성 블록을 조립 슬롯에 드래그.
- 조합 규칙 시각화: 중성 종류(세로형 ㅏ/ㅓ, 가로형 ㅗ/ㅜ, 복합형 ㅘ)에 따라 슬롯 레이아웃이 애니메이션으로 변형.
- **조립 완성 순간 해당 음절 발음 재생 + 글자가 "살아나는" 완성 연출** (스케일 바운스 + 글로우 + 햅틱).
- 유니코드 조합: `0xAC00 + (초성idx × 588) + (중성idx × 28) + 종성idx`. 전 11,172 음절 지원, 커리큘럼은 빈도 상위 음절부터.
- 오답 블록 배치 시: 슬롯이 거부 진동, 왜 안 되는지 1줄 힌트(예: "ㅇ은 받침 자리에도 올 수 있어요").

**3단계 — 단어 러시 (🔒 프리미엄)**
- 완성 글자로 구성된 실생활·K-컬처 일반명사 어휘(음식: 김치·비빔밥, 감정: 사랑·행복, 일상: 안녕·감사).
- 저작권 있는 고유명사(그룹명·인명·작품명)·가사 금지 — 어휘 데이터 리뷰 체크리스트에 포함.
- 단어 발음 재생 + 텍스트 → 4지선다 이미지 매칭, 남은 시간 비례 보너스.

**4단계 — 발음 도전 (🔒 프리미엄)**
- iOS Speech framework(온디바이스) 우선. 자모·단어 발음 → 인식 결과와 목표의 유사도 채점(0–100).
- 채점 로직은 교체 가능한 `PronunciationScorer` 모듈. 시각 피드백: 파형 + 점수 링 + 재도전.
- 웹/미지원 환경: 자동 비활성화(graceful degradation) — 스테이지 노드에 "이 기기에서 지원되지 않음" 상태.

### 3.2 적응형 출제
- 자모별 오답 카운트 추적(`ErrorTracker`). 출제 가중치 = 기본 1.0 + 오답률 × 가중 계수.
- 최근 5회 연속 정답 시 가중치 감쇠. 데이터는 로컬 저장, SRS(스마트 복습)와 공유.

### 3.3 리텐션 장치
- 일일 스트릭(플레임), 데일리 챌린지(일 1회 믹스 라운드), 레벨/뱃지.
- **7일 한글 완독 트래커**: Day1 기본 자음 → … → Day7 문장 읽기. 온보딩 약속과 동일한 UI 언어로 홈 상단 고정.
- 주간 리그: 로컬 랭킹(봇 리그, 서버 불필요). XP 기반 승급/강등.

## 4. 학습 레이어 (게임 루프 종속 — 독립 커리큘럼 금지)

1. **자모 도감** (무료): 게임 중 자모 첫 조우 시 카드 해금, 마스터 시 카드 승급(홀로그램 등급).
   카드 구성: ① 원어민 발음 ② 소리-형태 원리 애니메이션(자음=조음기관 상형, 모음=천지인) ③ 획순 애니메이션 ④ 예시 단어 2~3개. 공유하고 싶은 일러스트 품질 목표.
2. **스마트 복습** (🔒, 무료 일 1회 맛보기): 오답 추적 + SM-2 계열 간격 반복으로 개인화 5분 세션 생성. 맛보기 종료 화면이 전환 트리거.
3. **원리 미니레슨** (무료): 스테이지 진입 전 ≤60초 인터랙티브 설명, 스킵 가능. 긴 강의·문법 금지.

## 5. 수익화

### 5.1 무료/프리미엄 경계

| 무료 | 프리미엄 |
|---|---|
| 1단계 전체 | 2단계 후반(레벨 6~) |
| 2단계 전반(레벨 1~5) | 3단계 전체 |
| 자모 도감, 미니레슨 | 4단계 발음 도전 |
| 스마트 복습 일 1회 맛보기 | 스마트 복습 무제한 |
| 데일리 챌린지, 스트릭, 리그 | 스트릭 복구(프리미엄 특전) |

시간제한(Drops식) 금지. 무료 구간(특히 2단계 전반)에 최고 품질 집중.

### 5.2 구독 상품
- 월간 `hq_premium_monthly` / 연간 `hq_premium_yearly`(할인 강조, 기본 선택). 7일 무료 체험.
- 결제: 스토어 인앱 구독 정공법. 웹앱 배포 시에만 Stripe. **스토어 빌드에 외부 결제 유도 문구·링크 금지.**

### 5.3 페이월 (전환율 최적화)
- 구성: 가치 요약 3줄("경쟁 앱에 없는 발음 피드백", "개인화 복습", "전체 스테이지") → 플랜 선택(연간 기본, 절약률 뱃지) → 7일 체험 CTA → 해지 안내 · 약관 · 처리방침 링크 · 복원 버튼.
- 노출 트리거 4곳: ① 2단계 후반 잠금 도달 ② 발음 도전 진입 ③ 복습 맛보기 종료 ④ 스트릭 복구 제안.
- 강제 광고·다크 패턴 금지(닫기 버튼 상시, 취소 흐름 은폐 금지).

### 5.4 이벤트 로깅 (Analytics 추상 인터페이스, 개발 단계 로컬 로거)

## 6. 플랫폼 추상화 (스토어 종속성 격리)

| 기능 | 인터페이스 | 구현체 |
|---|---|---|
| 결제 | `BillingGateway` | `MockBilling`(개발 기본) / `StoreKitBilling` / `PlayBilling` / `StripeBilling`(웹 전용) |
| 음성인식 | `SpeechRecognizer` | `IosSpeechRecognizer` / `UnsupportedSpeech`(자동 비활성화) |
| 발음 채점 | `PronunciationScorer` | `JamoSimilarityScorer`(교체 가능) |
| 햅틱 | `HapticsDriver` | `IosHaptics` / `NoopHaptics` |
| 푸시 | `PushDriver` | `LocalNotifPush` / `NoopPush` |
| 오디오 | `AudioAssetManager` | TTS 플레이스홀더 슬롯 → 성우 녹음 에셋 교체 가능 |

전환 조건: App Store 심사 지연 시 Google Play 선출시 또는 Flutter Web + Stripe. **코어 게임·학습 로직 수정 없이** 구현체 교체만으로 전환되어야 하며, 이는 `billing_switch_test.dart`로 검증한다.
과잉 추상화 금지: 위 표의 교체 지점 외 추상화를 만들지 않는다.

## 7. 저장/동기화
- 로컬 우선: 진도·오답·SRS·스트릭·도감·구독 캐시를 로컬 JSON 저장(`ProgressStore`).
- 추후 클라우드 동기화 대비: 스토어는 직렬화 가능한 단일 상태 트리 + 변경 타임스탬프. 동기화 어댑터는 **지금 만들지 않는다**(경계 준수).

## 8. App Store 심사 대응 체크리스트 (필수 구현)
- [ ] `NSMicrophoneUsageDescription`: "발음 도전 모드에서 회원님의 한국어 발음을 채점하기 위해 마이크를 사용합니다. 음성은 기기에서만 처리되며 저장·전송되지 않습니다." (ios/Runner/Info.plist)
- [ ] `NSSpeechRecognitionUsageDescription` 동일 취지 문구.
- [ ] 개인정보 처리방침: 설정 내 화면 + 외부 URL 연결 지점(`PrivacyPolicyScreen`).
- [ ] 구독 해지 안내 화면: 해지 경로(설정 > Apple ID > 구독) 명시(`ManageSubscriptionScreen`).
- [ ] 페이월에 가격·기간·자동갱신 고지, 이용약관/처리방침 링크, 복원 버튼.
- [ ] 스토어 빌드에서 외부 결제 링크·문구 부재 확인(빌드 플래그 검사).
- [ ] 마이크 권한 거부 시 앱 정상 동작(4단계만 비활성).

## 9. 경계(하지 않는 것)
소셜 로그인, 멀티플레이, 타 언어 확장, 손글씨 트레이싱, 문법 강의, 서버 랭킹, 클라우드 동기화 구현(구조만 대비). 학습 레이어는 §4의 3개가 전부.
