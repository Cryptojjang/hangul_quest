# HangulQuest — 디자인 아이덴티티 (v1.0)

목표: Duolingo(플랫 마스코트 + 초록)와 Drops(네온 그라디언트 + 검정) 스크린샷 옆에 놓았을 때
즉시 구별. 방향은 **"달항아리 미니멀 + 단청 액센트"** — 한지 질감의 웜 뉴트럴 바탕 위에
단청 5방색에서 추출한 절제된 액센트, 자모 블록은 도자기 질감의 촉감적(tactile) 3D-ish 타일.

## 1. 컬러 시스템 (semantic tokens — 코드의 `HqColors`와 1:1)

| 토큰 | 값 | 용도 |
|---|---|---|
| `hanji` | #F7F1E5 | 바탕(한지). 다크: #1C1A17 |
| `ink` | #2B2622 | 본문 텍스트(먹) |
| `dancheongRed` | #C4463A | 주 액센트, CTA, 콤보 |
| `dancheongBlue` | #2E5E8C | 보조 액센트, 중성 블록 |
| `dancheongGreen` | #4A7A5A | 정답, 진행률 |
| `obangYellow` | #E0A526 | 별, 스트릭 플레임, 하이라이트 |
| `celadon` | #A8C5B8 | 카드 배경(청자), 비활성 |
| `choseong` / `jungseong` / `jongseong` 블록 | Red/Blue/Green 계열 파스텔 | 2단계 블록 역할 구분 색 |

규칙: 화면당 액센트 2색 이하. 그라디언트는 도감 카드 홀로그램 등급에만 허용.

## 2. 타이포·형태
- 한글 표시: 커스텀 라운드 고딕 축(개발 단계: Pretendard 대체), 자모 블록은 획 대비가 또렷한 전용 렌더링.
- 코너 라운드 20px 통일, 카드 elevation 대신 2px 오프셋 하드 섀도(판화 느낌).
- 기본 Material 위젯 노출 금지 — 전 버튼/카드/다이얼로그 커스텀(`HqButton`, `HqCard`, `HqDialog`).

## 3. 모션·햅틱

| 순간 | 모션 | 햅틱 |
|---|---|---|
| 블록 픽업 | 1.08x 스케일 + 그림자 확장 | light |
| 블록 장착 | 슬롯 스냅 + 슬롯 레이아웃 morph | medium |
| 음절 완성 ★ | 글자 스케일 바운스 + 골드 글로우 + 파티클, 직후 발음 재생 | success(heavy) |
| 오답/거부 | 좌우 셰이크 6px | error(double tap) |
| 콤보 상승 | 콤보 게이지 펄스, 배경 채도 +5% | light 연타 |
| 카드 해금 | 카드 플립 + 홀로그램 스윕 | success |
| 화면 전환 | 좌→우 슬라이드 + 한지 페이퍼 텍스처 크로스페이드 250ms | — |

## 4. 도감 카드 (공유 욕구 목표)
- 세로 3:4, 자모 대형 레터폼이 주인공. 자음: 조음기관 상형 일러스트가 레터폼과 오버레이,
  모음: 천지인(하늘 점·땅·사람) 구성 요소가 조립되는 애니메이션.
- 등급: 기본(한지) → 마스터(청자 유약 + 홀로그램 스윕). 카드 하단 획순 미니 플레이어 + 예시 단어.
- 공유 이미지 내보내기는 v1 범위 외(경계 준수) — 카드 자체 품질만 목표.
